# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `master` branch.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **billylo1@gmail.com** with:

- A description of the issue
- Steps to reproduce (if possible)
- Impact assessment (if known)

You’ll get a reply when the report is received. Please allow reasonable time for investigation before any public disclosure.
